# Rust native Fusion checkpoint R21

R21 adds bounded absolute translation of an exact owned flat root occurrence,
followed by one explicitly guarded captured position. Rust controls admission,
units, stale guards, readback, result stages and the durable journal. C++ contains
only typed Autodesk ABI calls and retained SDK object holders.

The new occurrence_update operation requires
`native-root-occurrence-translation-v1`; prior operations and the primary
`native-root-assembly-v1` contract remain supported. Rotation, grounding edits,
unrelated pending positions, arbitrary object adoption, rollback and automatic
retry remain unsupported. See [the finite contract](docs/R21-OCCURRENCE-TRANSLATION.md).

The exact R20-fix3 186-file baseline is archived under evidence/baseline-source
and recorded by BASELINE-R20-FIX3-PRODUCT-FREEZE1.txt. All earlier frozen source
and live evidence remain unchanged. Prior unknown operations remain unknown.

This candidate is source-tested only. Root independent review, actual Windows
SDK build, protocol execution and independent SDK observation remain separate
gates. No host actions, Python, installation or publication were performed by
this author. Root-owned verification/native-placements is not part of the
product freeze and is not qualified by product unit tests.
